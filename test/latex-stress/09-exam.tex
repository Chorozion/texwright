\question[10] Simplify $\dfrac{x^2 - 1}{x - 1}$.
\begin{solution}
$\dfrac{(x-1)(x+1)}{x-1} = \dfrac{\cancel{(x-1)}(x+1)}{\cancel{(x-1)}} = x + 1$.
\end{solution}
